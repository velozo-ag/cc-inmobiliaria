# CC Inmobiliaria - Sitio Web Oficial

Sitio web inmobiliario desarrollado con Next.js 16 (App Router), React 19, JavaScript y Tailwind CSS v4 para **CC Inmobiliaria (Matrícula Profesional 20)** en Corrientes Capital.

## Rutas principales

- `/` - Portada editorial con buscador de propiedades, cartera destacada en USD, diferencial profesional y acceso directo a WhatsApp.
- `/catalogo` - Catálogo filtrable por palabra clave, tipología (`Departamentos`, `Casas`), zona y rango en USD.
- `/[slug]` - Ficha técnica individual de cada propiedad con galería interactiva, especificaciones, equipamiento y formulario de consulta a WhatsApp.

## Desarrollo local

```bash
npm install
npm run dev
```
